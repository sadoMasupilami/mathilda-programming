Heute entdeckt {{KIND}}, dass man ein Bild auch aufschreiben kann, ohne es zu zeichnen. Ein Kästchenbild besteht aus Kästchen, jedes ist weiß oder hat eine Farbe. Der Kästchen-Code beschreibt es Zeile für Zeile, von links nach rechts: „3 weiß, 2 schwarz, 3 weiß“. Wer den Code hat, kann das Bild malen, ohne es je gesehen zu haben. Und wer ein Bild hat, kann seinen Code aufschreiben, vorlesen oder verschicken.

Dazu kommen zwei alte Bekannte: Der Fehler-Kobold verändert eine Code-Zeile, und schon bekommt das Bild eine Delle. Und der Zauber-Kasten aus Einheit 5 macht den Code kürzer, wenn sich Zeilen wiederholen. Gemalt wird auf echten 1-cm-Kästchen, wie im Rechenheft. Ein großer Schwerer-Teil wartet mit Bildern in 10 · 10 Kästchen, zwei Farben, Rekord-Codes und einem Code ganz ohne Farben.

  • So sieht er aus: Für jede Zeile Zahl und Farbe, immer von links nach rechts. Auf den Blättern steht die Zahl neben einem kleinen Kästchen in der Farbe: heißt „3 weiß, 2 schwarz, 3 weiß“. Weiß heißt: Kästchen leer lassen, aber mitzählen.
  • Die Kobold-Probe: Die Zahlen einer Zeile ergeben zusammen genau die Breite des Bilds, hier 3 + 2 + 3 = 8. Kommt etwas anderes heraus, hat der Kobold zugeschlagen.
  • Gleiche Farben zusammen: Nebeneinander stehen nie zwei Teile mit derselben Farbe. Statt „1 schwarz, 1 schwarz“ schreibt man „2 schwarz“. Falsch ist die lange Form nicht, nur länger.
  • Kürzer mit dem Zauber-Kasten: Sind Zeilen untereinander gleich, kommt die Zeile in einen lila Zauber-Kasten: „3-mal: 1 weiß, 3 schwarz, 1 weiß“ malt drei gleiche Zeilen untereinander. Profis setzen den Kasten auch mitten in eine Zeile: „2-mal: 1 schwarz, 1 weiß, dann 1 schwarz“. Es gelten die Regeln aus Einheit 5: 2-mal bis 5-mal, in einer Zeile höchstens 3 Teile im Kasten, kein Kasten im Kasten.
  • Zahlen zählen: Wie lang ist ein Code? Man zählt die Zahlen, die man schreiben muss, genau wie die Karten in Einheit 5. Jeder Teil („3 weiß“) ist 1 Zahl, ein Zauber-Kasten ist 1 Zahl („3-mal“) plus alles, was darin steht.

Hintergrund

Jedes Bild auf einem Bildschirm besteht aus winzigen Kästchen, den Pixeln. Ein Handy-Bildschirm hat Millionen davon. Der Computer speichert für jedes Pixel eine Farbe als Zahl. Genau das macht {{KIND}} heute: Sie verwandelt ein Bild in Zahlen (das nennt man Codierung) und die Zahlen wieder zurück in ein Bild. Wer malt, ist dabei der Roboter, der Code ist sein Programm.

Der Kästchen-Code ist eine echte Technik, die Lauflängencodierung (englisch run-length encoding): Statt „weiß, weiß, weiß, schwarz, schwarz“ speichert man „3 weiß, 2 schwarz“. Bei Bildern mit großen einfarbigen Flächen spart das viel Platz. Faxgeräte haben ihre Seiten so verschickt, und manche Bildformate arbeiten heute noch so. Platz sparen heißt beim Programmieren Komprimieren. Der Zauber-Kasten für gleiche Zeilen ist schon die nächste Stufe: Muster erkennen und nur einmal speichern (wie in Einheit 5 und 6).

Die Kobold-Probe ist eine kleine Prüfsumme: Eine einfache Rechnung zeigt, ob Daten unterwegs kaputtgegangen sind. Computer machen das ständig, z. B. beim Herunterladen. Wie {{KIND}} heute gesehen hat, findet eine Prüfsumme aber nicht jeden Fehler: Der schlaue Kobold im Herz hat die Summe nicht verändert. Deshalb sind echte Prüfsummen raffinierter.

Wer diktiert und wer malt, müssen sich auf dieselben Regeln einigen: von links nach rechts, Zeile für Zeile, zuerst die Zahl. So eine Abmachung heißt Format. Beim Spalten-Diktat merkt man, wie wichtig sie ist. Der Nur-Zahlen-Code aus dem Schwerer-Teil braucht nur noch zwei Zustände, weiß und schwarz: Das führt direkt zu den Ja/Nein-Zahlen in Einheit 9.

Dasselbe 1-cm-Kästchenpapier kennt {{KIND}} aus dem Rechenheft der Rechen-Werkstatt: Dort steht in jedem Kästchen eine Ziffer, hier bekommt jedes Kästchen eine Farbe.

Code bauen (Level 3 und 4): Das Bild ist fertig, die Code-Zeilen sind leer. Jede Taste ist ein ganzer Teil, Zahl und Farbe zusammen, genau wie im Code am Blatt („3 weiß“, „2 schwarz“). Eine Zeile antippen wählt sie zum Ändern, die Taste mit dem roten Kreuz löscht ihren letzten Teil. „Fertig“ prüft: Jeder Code, der genau das Bild malt, bekommt den Stern. Kobold-Zeile reparieren (Level 5 und 8): Die App malt das Bild selbst aus dem Code mit der Kobold-Zeile. {{KIND}} tippt die verdächtige Zeile an (im Bild oder im Code). Ruhig: Die App bewertet nur das Ergebnis, mit derselben Rechnung wie die Lösungen in diesem Heft. Kein Zeitlimit, kein Fehlerton, kein Leben-Verlieren. „Nochmal“ fängt das Level von vorne an, ein Doppeltipp auf ein Kästchen malt es nicht gleich wieder weiß.

Wann weglegen: Nach Level 8 kommt „Super! Jetzt zurück zum Papier.“ Dann ist Schluss, auch wenn noch Zeit wäre. Wer noch Lust auf Kästchen hat: lieber die Kästchen-Karte für Oma.
